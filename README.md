# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 换乘窗内异线拼接 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 换乘拼接 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 灌「换乘窗内样例」「换乘窗外样例」→ 看换乘拼接
# → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿；换乘续腿挂回原行程键 |
| 行程账 | 进站+出站成对后的正式行程；拼接后一键多段 |
| 换乘点 | 窗内异线再进的凭据：同卡出站→进站、前/后线、间隔秒 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 换乘点 ↔ 旁路命运互证 |

## 换乘拼接口径（全局唯一）

选定架构：**以「窗内拼一程」为准（拼接）**。

- 出站即结第一程；同卡出站后 `站规.换乘窗秒` 内**异线**再进站 → 延伸同一行程键并写换乘点。
  一键含换乘点，四笔刷卡（进-出-进-出）同挂一键。
- **窗外**再进站按新行程处理，与新开腿同为两键；与拼/分段架构正交。
- **同线**再进站不拼接，两键可核（串味守卫：禁止把第二进站挂进已结第一程）。
- 拼接三写（写换乘点 + 改行程账 + 开续腿）在同一事务 savepoint 内；第二进站要么整段拼入、
  要么整段不入，**禁止半挂已结第一程**；一笔刷卡只挂一个行程键（库级触发器兜底）。
- 续腿被重复进站 / 缺腿超时旁路时，整段撤销延伸：换乘点作废、行程账还原、刷卡摘键。
- 分段口径下窗内异线再进必须产生**两个**独立行程键；两种口径以
  `拼接或分段标记` 与窗内再进的**行程键个数**（拼接=1、分段=2）区分。

### 只读接口

| 接口 | 返回 |
| --- | --- |
| `GET /api/换乘` | 全卡换乘视图列表 |
| `GET /api/换乘/卡?卡号=` | 单卡：卡号、换乘窗秒、行程键列表、拼接或分段标记、valid、问题 |
| `GET /api/换乘点?卡号=&状态=` | 换乘点明细（出/进站事件、前/后线、间隔秒、窗秒） |

### 夹具

| 夹具 | 演示 |
| --- | --- |
| `换乘窗内样例` | 乙窗内异线再进 → **一键含换乘点**；甲窗内同线再进 → **两键可核** |
| `换乘窗外样例` | 窗外再进 → 新开程（两键） |
| `换乘并发样例` | 拼键与开腿并发 → 一刷卡不得挂两行程键 |
